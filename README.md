## Install

### Through NPM

```bash
pnpm add reseter.css
# or
npm install reseter.css
```

### Through CDN

```html
<link rel="stylesheet" href="https://cdn.jsdelivr.net/npm/reseter.css@3.0.1/dist/index.min.css">
```

Load your CSS **after** reseter.css.
